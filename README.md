# cute-kitten-picture

A cartoon kitten holding a heart, drawn from code: signed distance fields, painted shape by shape with
anti-aliasing, written as a PNG with the Python standard library alone. Entered in make.fun's
[cutest-picture-01](https://make.fun/bounty/cutest-picture-01) bounty.

```sh
ENTRY_OUT=entry.png python3 main.py
```

The same bytes every run. MIT licensed.
